CATEGORY C — Abstraction, Interface, Class vs Interface

Five standalone Java solutions corresponding to the five problems in the assignment PDF.

Compile and run any one from this directory:
  javac Q1_MovieTicketCounter.java
  java Q1_MovieTicketCounter

Repeat with Q2_ParcelShippingDesk, Q3_CollegeFeeCounter, Q4_CityCabFareMeter,
or Q5_HomeApplianceEnergyReport.

Each source file is standalone and has its own public main class. Supporting classes and
interfaces are kept in the same file so it can be compiled directly with javac.
